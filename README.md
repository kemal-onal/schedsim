#SchedSim

* Run the following commands to compile and run the program. 
```
make
./schedsim
```

* Run the following command to run all test cases.
```
make testcases
```

* Run the following commands to grade your the program.
```
make grade
```

* Run the following commands check a single test case.
```
python3 test/checker.py <executable> <input_file> <output_file> <expected_output_file>
```

* Run the following commands to grade your the program with given paths.
```
python3 test/grader.py <executable-path> <test-cases-path>
```

* Installation
  Clone the repository to your local environment:
```bash
git clone [https://github.com/kemal-onal/schedsim.git](https://github.com/kemal-onal/schedsim.git)
cd schedsim
```
